# first-principles-thermal-noise-backscatter
First-Principles Channel Model and Capacity-Achieving Transmission Scheme in Thermal Noise Backscatter Links

The figures in the paper can be recreated by the corresponding script. To run `decode_example.m`, first download the data file `example_decode_data.mat` from the release page and paste it into folder `rawmeasurements`.
